# Project Overview

## Objective

Analyze customer lead data in Microsoft Excel to identify the main drivers of revenue and conversion performance.

## Business Questions

1. How many leads entered the pipeline?
2. What percentage converted?
3. Which lead sources perform best?
4. Which products/services generate the strongest results?
5. Which regions generate the most revenue?
6. How do customer types compare?
7. Which areas should management prioritize?

## Deliverables

- Excel customer dataset
- Excel executive dashboard
- KPI analysis
- Business findings
- Recommendations for management

## Tool Used

Microsoft Excel only.
