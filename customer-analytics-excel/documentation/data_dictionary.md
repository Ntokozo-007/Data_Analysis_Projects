# Data Dictionary

| Field | Description |
|---|---|
| Lead ID | Unique lead identifier |
| Call Date | Date associated with the lead call |
| Agent Name | Sales/contact agent handling the lead |
| Customer Name | Customer associated with the lead |
| Lead Source | Channel through which the lead originated |
| Call Status | Outcome/status of the call |
| Call Duration (Min) | Call duration in minutes |
| Follow-up Status | Current follow-up state |
| Conversion Status | Whether the lead converted |
| Revenue Generated | Revenue attributed to the lead |
| Region | Geographic region |
| Product/Service | Product or service associated with the lead |
| Customer Type | New Customer, Existing Customer, or Prospect |
| Year | Year extracted from Call Date |
| Month | Month extracted from Call Date |
| Quarter | Quarter extracted from Call Date |
